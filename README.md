## 📖 Descripción

**Among Creators Pack** es un paquete de recursos para creadores de contenido, enfocado principalmente en **Among Us**, aunque con el tiempo se ha ido expandiendo hacia otros ámbitos. Fue creado originalmente por **LeonelB2840**, con su desarrollo iniciado el **19 de julio de 2026** y su primera versión completa y oficial publicada entre el **20 y el 24 de agosto de 2026**.

### 🎁 ¿Qué incluye?

- 🎭 Memes
- 🖌️ Pinceles
- 🧩 Plantillas para tu personaje de Among Us y para tu foto de perfil
- 🎵 Músicas
- 🔊 Efectos de sonido
- 🖼️ Fondos
- ✨ Texturas para miniaturas
- 👾 Impostores de *VS. Impostor* e *Impostores Malditos*
- 🎨 Artes conceptuales

**¡Y mucho más!**

## 🌐 Página web

El proyecto cuenta con una página web con las siguientes características:

- ✅ Diseño responsivo (móvil, tablet, escritorio)
- ✅ **PWA** instalable (funciona como app en tu dispositivo)
- ✅ **Service Worker** con soporte offline
- ✅ Formulario de feedback con **calificación** (vía Formspree)
- ✅ Sección de **Novedades**
- ✅ Enlaces de descarga (Drive + acortador)
- ✅ Información de licencia y política de fans

### Estructura del proyecto

among-creators-pack/
├── index.html → Página principal
├── gracias.html → Renderiza gracias.md con estilo
├── gracias.md → Agradecimientos internos del equipo
├── manifest.json → Configuración PWA
├── sw.js → Service Worker
├── offline.html → Página de respaldo offline
├── README.md → este archivo
├── LICENSE → Licencia CC BY-SA 4.0
├── .gitignore Archivos ignorados por GitHub
└── icon.png → Icono de la PWA
